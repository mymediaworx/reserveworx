- A platform administrator can remove someone else’s platform access from `/platform/administrators`, from `DELETE /api/v1/platform/administrators`, or with `php artisan reserveworx:revoke-platform-admin`. The user account, password, and workspace memberships stay. The last remaining administrator cannot be removed. An administrator cannot remove their own access while another administrator exists. When they are the last one, the refusal says the last administrator stays. An unknown email, or a person who is not an administrator, is not found. Opening the list does not write an audit row. Removing access writes `platform.admin_revoked` with the email and no password. The page, the API, and the command do not write a price, a payment, a tax, a fee, or a refund. Someone who is not a platform administrator is refused. A tenant address is not found. The list wraps on a 390px-wide screen. Spec Section 12 and Spec Section 3.
