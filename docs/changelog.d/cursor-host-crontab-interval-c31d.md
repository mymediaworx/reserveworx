- `reserveworx:hosting-check` reads the user crontab. `host_crontab` is `read`, `empty`, or `unavailable`. A `schedule:run` line prints its five-field expression, or a known `@` alias, and the shortest gap in minutes. The command text, a path, and an assignment are not printed. A line that is not a user crontab schedule is `unparsed`, and the interval stays `unparsed`. An empty crontab and a missing `crontab` command do not fail the check.
