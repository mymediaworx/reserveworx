- Staff home lists today’s schedule from each location’s own date. A visit that is still today in Los Angeles stays on the list when the first location has already reached the next day in New York, and a visit that was yesterday there stays off. A rental that started yesterday and is still out today stays. A cancelled booking stays off. A location stored as UTC uses the UTC date. A location zone that is not a real name uses the business zone. The next-7-days count uses that same local day, so a visit that is still today is not counted as upcoming. A member limited to one location does not see another location. Another workspace is not listed. Spring-forward and fall-back days use that location’s clock, including the 23-hour evening and the 25-hour evening. The price, payments, taxes, and fees stay as they were.
