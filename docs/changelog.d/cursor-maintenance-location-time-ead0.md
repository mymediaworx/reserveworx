- Maintenance windows on `/staff/maintenance` name the start and end in that location’s timezone, with the abbreviation. A window that crosses a daylight-saving change names both. An early end and an overlapping booking use that same clock. A repeated hour starts at the earlier time and ends at the later time. A time that does not exist is not saved. The location zone wins over the business zone. A location stored as UTC still shows UTC. A location zone that is not a real name uses the business zone. Another workspace’s window is not listed. The price, payments, taxes, fees, and refunds stay as they were. The time line wraps on a 390px-wide screen. Spec Section 2.4.
