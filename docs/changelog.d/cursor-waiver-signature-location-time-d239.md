- `/staff/bookings/{booking}` names each signed waiver in that booking’s location timezone with the abbreviation. On a fall-back morning, 1:30 AM EDT and 1:30 AM EST stay distinct. A spring-forward signature uses the abbreviation for that instant. A location stored as UTC stays UTC. A zone that is not a real name uses the business zone. Another workspace’s signer is not listed. Opening the page does not write a price, a payment, a tax, a fee, or a refund. Stored `signed_at` stays UTC. The time line wraps on a 390px-wide screen. Spec Section 2.4.
