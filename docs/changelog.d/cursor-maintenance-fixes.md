- Fixed the inode guard and the maintenance action on the SiteGround SSH host. The first maintenance run printed `maintenance_inodes_before=1` because `du --inodes -s -x "$HOME"` stops at a mount boundary there, and it stopped at the secret-file listing because the host has no `/dev/fd` for process substitution. The account count now follows the real home and uses the larger of the counts with and without `-x`, the report prints both plus `find` counts for the home, the breakdown repeats without `-xdev` when `-xdev` finds nothing, and the script no longer uses process substitution.
