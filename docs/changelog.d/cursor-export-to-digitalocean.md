- Added an `export-to-digitalocean` action to the existing Deploy workflow, plus `scripts/import-dump-digitalocean.sh`. A manual run takes a fresh verified database dump through the existing backup action, streams it and the public storage over SSH to the DigitalOcean rehearsal server, imports them there, empties the imported queue, and prints per-table row counts and the mail, scheduler and payment settings. It reads SiteGround only, apart from the one new dump file. The data is kept on the droplet only, and the transfer files are deleted afterwards.
