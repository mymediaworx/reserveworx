- After a healthy SiteGround deploy, the script prints `cron_check`. `present` means the user crontab has a `schedule:run` line. `missing` means that line is absent. `empty` means there is no crontab. `unavailable` means the crontab could not be read. A comment and an assignment do not count. The command, a path, and the crontab text are not printed. The script does not install a crontab. A result other than `present` does not fail the deploy. No price, payment, tax, fee, or refund is written. Spec Section 16.
