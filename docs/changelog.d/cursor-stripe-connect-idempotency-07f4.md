- Linking a Stripe account accepts an idempotency key. The same key and the same request return the stored connected account and do not open a second onboarding link. A different request for that key is refused. A key longer than 80 characters stores nothing. A request with no key still opens another link for the account the workspace already has. The remembered row keeps the key and a hash, not the email or the onboarding address. Prices, taxes, fees, and refunds stay as they were. Spec Section 13.
