- The staff calendar names each booking and tour departure as its start and end in that location’s timezone. A visit that crosses a daylight-saving change names both abbreviations, so 1:30 AM EDT and 1:30 AM EST stay distinct. A location stored as UTC still shows UTC. A zone that is not a real name uses the business zone. The time line wraps on a 390px-wide screen. Spec Section 2.4.
