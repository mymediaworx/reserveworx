- Staff reports name each tour departure’s start and end in that location’s timezone, with the abbreviation. A departure that crosses a daylight-saving change names both. On the fall-back morning, 1:30 AM EDT and 1:30 AM EST stay distinct. The location zone wins over the business zone. A location stored as UTC still shows UTC. A location zone that is not a real name uses the business zone, including which local date the departure is listed on. Another workspace’s departure is not listed. The staff CSV uses that same clock and keeps the local date. The tours API keeps the local civil start and adds the same wording as `when`, including on the CSV. Opening the report does not write a price, a payment, a tax, a fee, or a refund. Stored instants stay UTC. The time line wraps on a 390px-wide screen. Spec Section 2.4.
