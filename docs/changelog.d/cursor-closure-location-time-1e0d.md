- `/staff/closures` names each closure as its start and end in that location’s timezone, with the abbreviation. A window that crosses a daylight-saving change names both, so on a fall-back morning 1:00 AM EDT and 2:00 AM EST stay distinct, and a spring-forward window names EST and EDT. Overlapping confirmed bookings use that same clock. A held booking and a cancelled booking stay off the list. A booking that only touches the end stays off that window. The location zone wins over the business zone. A location stored as UTC still shows UTC. A location zone that is not a real name uses the business zone. Another workspace’s closure is not listed. Opening the page does not write a price, a payment, a tax, a fee, or a refund. Stored wall-clock times stay as entered. The time line wraps on a 390px-wide screen. Spec Section 2.4.
