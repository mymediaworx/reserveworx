- Added an opt-in `purge_opcache` input (default off) to the maintenance action of the Deploy workflow. When it is on, maintenance deletes only the contents of the account's `.opcache` folder, which can hold most of the account's inodes, and keeps the folder itself. It refuses unless the path is exactly the real home's `.opcache` and a real directory, never follows a symlink out of it, and logs `opcache_inodes_before`, `opcache_inodes_after` and the account totals before and after. Nothing else is touched and no other default changes.
