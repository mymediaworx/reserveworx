- `/staff/returns` keeps both hours when a rental comes back on a fall-back morning. A plain clock is the earlier hour, and the later hour can be chosen. A spring-forward time that does not exist is refused and the checkout stays out. A location stored as UTC stays a plain clock. A zone that is not a real name uses the business zone.
